# Portofolio Galih Jayaningrat

Situs portofolio statis untuk GitHub Pages. Semua halaman ada di `index.html`.

## Cara memasang
1. Buka repository `Galihputraa/galihjayaningrat.github.io` di GitHub.
2. Pilih **Add file → Upload files**.
3. Unggah `index.html` dan `README.md` dari folder ini ke lokasi utama repository, lalu pilih **Commit changes**.
4. Jika GitHub Pages belum aktif: buka **Settings → Pages**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Buka `https://galihjayaningrat.github.io` setelah proses publikasi selesai.

## Sesuaikan sebelum dipublikasikan
- Di `index.html`, ganti teks bagian **Tentang**, label minat, dan tiga proyek dengan informasi yang benar.
- Ubah URL pada tautan proyek agar menuju demo atau repository yang sesuai.
- Tambahkan tautan email atau media sosial di bagian **Terhubung** jika ingin.

Situs menggunakan HTML dan CSS biasa, tanpa proses build atau dependensi tambahan.
